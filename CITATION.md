# How to cite AstroGuard-QFV

## Experiment data and results

Use the depositor-provided, version-specific Zenodo DOI:

**[10.5281/zenodo.23770646](https://doi.org/10.5281/zenodo.23770646)**

For the final bibliography entry, use the record's **Cite / Export** feature to obtain its exact verified title, creators, publication date, and version. Do not substitute the GitHub software title for the Zenodo record title unless they are identical.

## Reproducibility code

AstroGuard-QFV 18K experiment source. GitHub repository: https://github.com/Shubha-fm/AstroGuard-QFV. Cite a specific release tag or commit hash in methods and reproducibility statements.

The GitHub source repository and the Zenodo data/results record are **separate research resources**. The supplied DOI is not asserted to be a software DOI.

## Original observational sources

Credit the Zwicky Transient Facility (ZTF) and the ALeRCE broker as data providers, following their applicable citation and reuse guidance. The ALeRCE broad-class labels in this experiment are broker pseudolabels, not independently verified labels.
