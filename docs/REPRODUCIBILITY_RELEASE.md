# Reproducibility release and Zenodo record

The project depositor supplied the archive DOI: **[10.5281/zenodo.23770646](https://doi.org/10.5281/zenodo.23770646)**.

The repository records this DOI but does not automatically validate the remote deposit. Before finalizing a manuscript availability statement, check the Zenodo record page for:

1. **File inventory:** exact `.tar.gz` and optional compact ZIP filenames; whether data, models, predictions, TLC logs and other outputs are included.
2. **Integrity:** a SHA-256 checksum calculated for the **deposited** file, not an earlier working archive or differently cleaned version.
3. **Reuse rights:** applicable ZTF/ALeRCE attribution and redistribution conditions, and the license declared on the Zenodo record.
4. **Privacy:** any archived SQLite progress databases, Mac `._` metadata, absolute user paths, environment secrets, or historical `ERROR.log` files.
5. **Scientific provenance:** class-filtered 18,000-object cohort with broker-generated pseudolabels; object-disjoint splits of 11,700/2,699/3,601 and five-seed trials.
6. **Citation:** exact Zenodo record metadata from its own citation exporter, and the GitHub revision used to generate the outputs.

If corrections to published files are required, create a new Zenodo version and document the new version-specific DOI. Do not silently replace dataset metadata or imply that a DOI proves data-provider redistribution permission.

The compiled manuscript and LaTeX sources are intentionally absent from the public software repository.

The author's pre-upload size check on 29 October 2026 reported approximately 309 MB in `input/`, 1.4 GB in `RESULTS_18K/`, and a combined gzip archive of 521 MB. These are local filesystem figures, not a remote Zenodo file-size verification.
